# HE-MedInfer: Homomorphic Encryption-Enabled Secure Machine Learning Inference for Privacy-Compliant Healthcare Diagnostics Without Data Decryption

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![LaTeX](https://img.shields.io/badge/Built%20with-LaTeX-blue.svg)](paper/Artigo14.tex)

## Abstract

The proliferation of machine learning in clinical decision support systems has created an urgent
demand for inference pipelines that operate directly on sensitive patient data without ever
exposing it in plaintext. We propose **HE-MedInfer**, a three-tier homomorphic encryption (HE)
framework that enables end-to-end encrypted ML inference for healthcare diagnostics, requiring no
data decryption at any point in the pipeline. HE-MedInfer integrates CKKS-based approximate
arithmetic with a calibrated polynomial approximation of non-linear activations, and introduces
the **HE Privacy Index (HEPI)**, a composite metric that jointly quantifies ciphertext security,
computational overhead, and inference accuracy degradation under encrypted computation.

## Status of results in this repository

This repository is under active development. Results fall into two categories, and each artifact
in `results/` is labeled accordingly:

- **Measured** — produced by actually running the code in `src/` (real PyTorch training, real
  TenSEAL/Microsoft SEAL CKKS encryption and homomorphic inference, real Opacus DP-SGD). These
  numbers are reproducible by re-running the corresponding script against `data/cohort.csv`.
- **Synthetic cohort, not real patient data** — `data/cohort.csv` is generated by
  `src/datagen/cohort_generator.py`, a Gaussian-copula generator fitted to *published* MIMIC-III /
  Harutyunyan et al. (2019) summary statistics. No individual-level MIMIC-III record is read,
  stored, or required to reproduce anything in this repository — see
  [`src/datagen/cohort_generator.py`](src/datagen/cohort_generator.py) for the exact generative
  model and [`paper/Artigo14.tex`](paper/Artigo14.tex) (Section "Clinical Task, Cohort, and Data
  Generation") for the full methodological discussion, including what does and does not transfer
  to real clinical data.

Current measured results (`results/plaintext.json`, 10 runs, seed 42-51): plaintext MLP
AUROC = 0.8615 ± 0.0009, accuracy = 89.1% ± 0.2% on the synthetic in-hospital-mortality cohort.
Real CKKS homomorphic inference, DP-SGD, and the Lee et al. baseline are implemented in
[`src/he_inference.py`](src/he_inference.py), [`src/train_dpsgd.py`](src/train_dpsgd.py), and
[`src/lee_baseline_he.py`](src/lee_baseline_he.py) respectively; their result files are added to
`results/` as each run completes.

## Reproducing the pipeline

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 1. Generate the synthetic cohort
python -m src.datagen.cohort_generator --n-stays 21139 --seed 42 --out data/cohort.csv

# 2. Train the plaintext MLP (upper-bound baseline)
python -m src.train_plaintext --data data/cohort.csv --runs 10 --device cuda:0 \
    --out results/plaintext.json --model-out results/plaintext_model_seed42.pt

# 3. Train the DP-SGD baseline (epsilon=1.0, delta=1e-5)
python -m src.train_dpsgd --data data/cohort.csv --runs 10 --device cuda:0 \
    --out results/dpsgd.json

# 4. Real CKKS homomorphic inference (CPU-bound; parallelized across the
#    machine's core count via multiprocessing)
python -m src.he_inference --model results/plaintext_model_seed42.pt \
    --data data/cohort.csv --ckks-n 15 --workers 64 --out results/he_medinfer.json
```

Steps 2 and 3 run on a CUDA GPU; step 4 (homomorphic inference) is CPU-only, since Microsoft SEAL
does not currently support GPU execution — this repository's development used a GPU-accelerated
compute cluster with a large core count for step 4's process-level parallelism.
